又到了「期末報告要交什麼」的靈魂拷問時刻！別擔心，這份指南已經幫你把這學期在職能發展學院學到的看家本領——**TXT／CSV 檔案讀寫**、**函式模組化**、**把程式從閃退邊緣拉回來的 `try / except`**、**證明自己沒亂寫的單元測試**，還有**永遠忠誠的 `uv` 虛擬環境**——全部打包成三個風格迥異、上台報告又好講故事的大綱方向。挑一個最順眼的，就可以安心開寫啦！

## 二、方向一（實用應用類）：個人記帳與消費分析系統

- **建議報告題目**：《錢到底花去哪裡了？——基於 Python 之個人記帳與消費分析系統》
- **為什麼寫這個**：月底看戶頭餘額總是像懸疑片？市面上的記帳 App 功能多到像在開飛機，乾脆自己用 Python 寫一個清爽的終端機（CLI）記帳小管家，順便練習怎麼把資料存進檔案、怎麼防止自己手滑把金額打成「一杯大冰奶」而讓程式當場陣亡。
- **偷偷展示的 Python 實力**：
  - 用 `csv` 或 `json` 把每一筆消費牢牢鎖在硬碟裡（重開機錢也不會回來，但紀錄都在）。
  - 把「記一筆、查帳、算總和、存檔」切成乾淨的小函式，告別幾百行擠成一坨的義大利麵程式碼。
  - 派出 `try / except` 當守門員：日期打錯、金額輸入負數或亂碼、檔案不見，通通溫柔攔截不閃退。
  - 寫幾個單元測試，證明「100 + 250」絕對不會算成 500。

### 報告章節大綱
1. **前言：月底吃土的痛點與專題動機**
   - 為什麼記帳總是三天打魚兩天曬網？（順便吐槽太花俏的商業 App）
   - 本專題的目標：輕量、免連網、只做真正用得到的功能。
2. **需求盤點：我的記帳小管家要會做什麼？**
   - 核心技能樹：新增／修改／刪除收支、依月份與類別查帳、列出誰是本月吞錢怪獸（類別統計）。
   - 使用者操作路線圖：主選單怎麼逛才不會迷路。
3. **系統架構與資料長相**
   - 專案資料夾開箱（主程式、邏輯模組、`tests/` 測試區、`uv` 環境管理）。
   - 帳本欄位設計（日期、收支類型、分類、金額、碎碎念備註）與 CSV／JSON 存檔格式。
4. **核心實作與防呆設計（工程師的自我修養）**
   - 模組化函式介紹：各司其職，誰都不搶誰的工作。
   - 防呆守門員實錄：用 `try / except` 接住 `ValueError`、`FileNotFoundError`，不讓使用者一鍵把程式搞崩。
5. **測試結果與成果展示（有圖有真相）**
   - 單元測試跑綠燈的療癒畫面（含正常測試與故意亂輸入的邊界測試）。
   - 實際記帳與月結報表執行畫面展示。
6. **結語、心得與未來白日夢**
   - 寫程式過程中最常卡關的地方與 Debug 血淚史。
   - **加分彩蛋區**：花超過預算自動跳出靈魂警告、一鍵匯出 Markdown 月報或 ASCII 長條圖。

## 三、方向二（資料分析類）：台灣開放資料（Open Data）清洗與洞察分析

- **建議報告題目**：《別讓髒資料騙了你！台灣開放資料清洗與趨勢分析——以【YouBike 借還 / 空氣品質 / 實價登錄】為例》（請任選一位幸運嘉賓）
- **為什麼寫這個**：政府開放資料平台上有海量的免費寶藏，但下載下來打開常常像剛經歷過一場地震——空值、亂碼、怪日期應有盡有。這個題目就是要展現你如何用 Python 當資料清道夫，把混亂的原始 CSV 洗乾淨，再挖出連新聞都沒告訴你的有趣真相！
- **偷偷展示的 Python 實力**：
  - 讀取大型 CSV／TXT 檔案，優雅化解 UTF-8 與 Big5 的世紀恩怨。
  - 運用函式加上 `try / except` 過濾缺失值與格式異常的怪資料，讓清洗管線穩穩跑完不卡死。
  - 自己寫統計函式算出平均值、極值、尖離峰差異與區域排行榜。
  - 把冷冰冰的數字整理成讓人一看就懂的摘要表格或視覺化圖表。

### 報告章節大綱
1. **開場：為什麼挑這份資料？我想問它什麼問題？**
   - 選題動機與好奇心（例如：「下班時間到底哪個 YouBike 站最容易看著空柱嘆氣？」）。
   - 資料來源履歷表（出處、格式、時間區間與原始欄位介紹）。
2. **資料大掃除：那些資料裡藏著的奇葩問題**
   - 髒資料圖鑑：空白欄、重複列、負數時間、神奇的編碼錯誤。
   - 清洗流水線與 `try / except` 急救包：遇到壞資料怎麼跳過並統計「共淘汰了多少筆雷包資料」。
3. **指標設計：怎麼評斷誰是第一名？**
   - 定義關鍵指標（例如：站點週轉率、空品超標天數比例、各區房價中位數）。
   - 分組計算與統計函式的實作邏輯。
4. **真相揭曉：數據分析結果與圖表時間**
   - 重點發現大公開（搭配清爽表格或趨勢／長條圖，讓評審眼睛一亮）。
   - 不同區域或時段的交叉對決與異常現象解讀。
5. **所以結論是？給生活與決策的實用建議**
   - 把分析結果翻譯成人話（例如：建議調度時段、出門看天色指南或購屋避坑小抄）。
6. **誠實時間：研究限制與下次可以更強的地方**
   - 坦承樣本期間或資料欄位本身的天花板。
   - **加分彩蛋區**：串接公開 API 自動抓最新資料、一鍵把分析結果寫成漂亮的 Markdown 摘要報告。

## 四、方向三（職場自動化類）：日常辦公檔案與多表合併自動化工具

- **建議報告題目**：《從加班地獄到準時下班：多表報表自動化合併工具之開發與實測》
- **為什麼寫這個**：每到週五或月底，就要打開 20 個部門寄來的 CSV／TXT 檔案，一個一個複製、貼上、刪空白列、核對金額，貼到眼睛快抽筋還怕漏掉一家門市？這個專題專治各種「人工複製貼上職業傷害」，用 Python 幾秒鐘搞定原本要花半小時的苦差事！
- **偷偷展示的 Python 實力**：
  - 用標準函式庫（如 `pathlib`、`csv`）一次把整個資料夾的檔案掃描進來。
  - 透過函式進行欄位對齊、重複列踢除、金額加總，最後優雅輸出乾淨總表。
  - 超實用的容錯設計：就算某個同事寄來的檔案壞掉或少一欄，靠 `try / except` 記進錯誤日誌就好，絕不連累其他 19 個正常檔案。
  - 準備「正常檔＋地雷檔」測試包，驗證程式真的能平安過關。

### 報告章節大綱
1. **職場鬼故事：手動整理報表的痛苦與自動化目標**
   - 還原悲慘日常（例如：彙整各門市日報表、收集大家交來的名單）。
   - 設定目標：把時間省下來喝飲料，順便把人為貼錯率降到零。
2. **案發現場重建：原本的手工作業到底哪裡慢？**
   - 步驟拆解與時間估算（開檔、複製、貼上、對齊、存檔，手腕都在哭）。
   - 經典悲劇盤點：漏掉最後一列、日期格式大亂鬥、檔案存錯名字。
3. **自動化救星登場：工具架構與處理流水線**
   - 流程圖：把雜亂檔案丟進 `input/` → 經過檢驗與整理 → 從 `output/` 吐出完美總表。
   - 程式模組拆解（掃描器、資料安檢門、合併引擎）。
4. **防呆與抓戰犯機制：遇到壞檔案怎麼辦？**
   - 刻意製造幾種職場常見災難（空檔案、欄位少一格、文字混進金額欄、編碼不合）。
   - 展示 `try / except` 如何冷靜隔離問題檔案，並自動生成一份 `error_log.txt` 告訴你「誰的檔案有問題」。
5. **效能大對決：人工 vs. Python 誰勝出？**
   - 殘酷實測比較表（人工 40 分鐘含眼神死 vs. Python 不到 2 秒鐘搞定）。
   - 測試案例全部 PASS 的驗證結果與輸出總表截圖。
6. **推坑同事指南與未來升級路線**
   - 寫一份連麻瓜同事都看得懂的極簡使用說明。
   - **加分彩蛋區**：用 `config.json` 自訂要抓取的欄位名稱、順便自動生成一份「老闆最愛看的一頁式摘要」。

## 五、選擇困難症救濟站 & 交件前最後檢查

### 三秒鐘決定你要寫哪個：
- 想秀出一個**自己就能天天用的小作品** ➔ 選 **方向一（記帳小管家）**
- 想看起來**很有研究精神、圖表很帥氣** ➔ 選 **方向二（開放資料分析）**
- 想在結訓或面試時大喊**「我真的能幫公司省時間！」** ➔ 選 **方向三（辦公自動化神器）**

### 期末報告防翻車檢核清單
- [ ] **題目別貪心**：先做出會動又穩定的 MVP（最小可行版本），有餘力再加炫砲功能，千萬別搞到報告前一天還在重寫架構。
- [ ] **程式碼別長成一坨**：乖乖拆成好讀的小函式與模組，附上一句看得懂的註解或 Docstring，一個月後的你會感謝現在的自己。
- [ ] **環境與套件有交代**：使用 `uv` 管理虛擬環境；如果有用 `uv add` 裝新套件，記得順手同步更新專案的 `requirements.md`！
- [ ] **`try / except` 保護傘撐好撐滿**：檔案不見、格式怪怪的、使用者亂打字時，程式都要能優雅回應，不能當眾噴出整頁紅色 Traceback。
- [ ] **先跑過測試再上台**：至少準備 3～5 個正常與異常的測試案例，確定全部綠燈通過。
- [ ] **Live Demo 永遠要有備案**：上台簡報前先把執行畫面截圖或錄成影片放進簡報裡，畢竟「平常都正常、上台就當機」是資訊界的莫非定律。
